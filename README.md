Robotik Kamera ile Nesne Tespiti – Vize Projesi

Öğrenci No: 202507130027
Ders: BLP105 – Veritabanı Yönetim Sistemleri

Projenin Amacı

Bu projede, robotik uygulamalarda kullanılan kamera tabanlı nesne tespit sistemlerinin incelenmesi amaçlanmaktadır.

İki farklı nesne tespit modelinin performansını, nesne sınıfları ve ışık koşulları açısından karşılaştırmak hedeflenmektedir.

Kullanılan Teknolojiler

- PostgreSQL
- SQL
- CSV veri dosyaları
- GitHub

Proje İçeriği

- Senaryo ve veri kaynağı açıklamaları
- Veri dosyaları
- SQL analiz sorguları
- Vize raporu
- Yapay zekâ kullanım beyanı

Teslim

Bu depo, BLP105 vize projesinin GitHub üzerinden incelenmesi amacıyla hazırlanmıştır.
